The Aftertaste

Manche Erfahrungen hinterlassen einen bitteren Nachgeschmack.

Das Konzept

Aus Enttäuschung wird eine kreative Idee.

Eine kurzfristig zurückgezogene Jobzusage wird zum Ausgangspunkt eines satirischen Kurzfilms. THE AFTERTASTE übersetzt eine persönliche Erfahrung in eine visuelle Geschichte über gebrochene Versprechen, Erwartungen und den schönen Schein.

Die visuelle Welt

Ästhetisch. Bitter. Bewusst irritierend.

Die Bildsprache verbindet hochwertige Werbeästhetik mit schwarzem Humor und symbolischen Details. Matcha wird dabei zum visuellen Leitmotiv und zum Sinnbild eines bitteren Nachgeschmacks.
